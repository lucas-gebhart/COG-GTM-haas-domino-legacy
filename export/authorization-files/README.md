Generated by `tools/generate_fixtures.py`. Each file corresponds to an `AuthorizationFile` document in
`export/dxl/vetmedals-documents.dxl` (matched on `FileName`) whose `ImportStatus` is `Received`: these are the
inbound batch that arrived after the last scheduled import, so `ImportAuthorizationFile` (LotusScript in
`nsf/vetmedals.nsf/agents/`, JavaScript port in `harness/lib/agents.js`) will process them when run from
the harness Agents menu. The veteran and next-of-kin names deliberately overlap earlier cases so the importer's
requester de-duplication is exercised.
